Akaa Séances : présence, avis et reçus (site Vercel)

1. Créer un projet Vercel nommé akaa-seances (importer ce dossier depuis GitHub, ou : vercel deploy dans ce dossier).
2. Storage > Create > Blob, accès PRIVÉ, connecté au projet (ajoute BLOB_READ_WRITE_TOKEN).
3. Settings > Environment Variables (Production) :
   ADMIN_PIN     = code d'accès organisateur (10 caractères ou plus)
4. Redéployer. Participants : /   Organisateur : /admin

Le code de séance (4 chiffres) n'est plus à configurer : il est généré automatiquement
à la première consultation de /admin pour chaque séance, et affiché là-bas pour
l'organisateur — il n'y a qu'à le lire et l'annoncer dans la salle.
